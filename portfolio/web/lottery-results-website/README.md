## 🌐 Overview · نظرة عامة

Interactive prototype of a lottery results platform: latest-draw hero card with winning numbers, bonus ball and prize-tier payouts; searchable, paginated archive of past draws with date/draw filters; hot/cold number frequency stats; share links; and an admin panel to enter new draws that appear live instantly. Built with React, responsive mobile-first UI.
