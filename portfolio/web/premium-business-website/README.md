## 🌐 Overview · نظرة عامة

Interactive prototype of a modern, premium multi-page business website: sticky responsive navigation with a mobile menu, Work/Services/About/Testimonials/FAQ sections, a validated contact form, a dark/light theme toggle, and a simple CMS-style 'Edit content' panel for easy updates. Built with HTML5, CSS3 and JavaScript, focused on fast loading and a clean UI.
