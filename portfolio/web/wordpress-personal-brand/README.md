## 🌐 Overview · نظرة عامة

Personal brand website design for a coach/consultant: a calm, editorial public site (hero, about, services, how it works, testimonials) with an inquiry form that emails the owner, plus a private client area unlocked by an access code — overview dashboard, session booking, resource library, rates and messages. Fully responsive layout, ready to be built on WordPress/Elementor from the client's chosen template. Built with HTML, CSS and JavaScript using mock content.
