## 🛒 Overview · نظرة عامة

Interactive prototype of a Shopify-style storefront rebuilt from a WordPress design: responsive homepage, course/product page, and a booking flow with calendar availability, service durations, buffer times, blackout dates, time-slot selection and confirmation screen.
