## 🛒 Overview · نظرة عامة

Working interactive demo of a conversion-focused online fashion store with admin dashboard.
- Storefront with collections, filters (category, size, price), search and product pages with variants and stock status
- Cart drawer and multi-step checkout with shipping/tax rules by country, discount codes and order confirmation
- Admin dashboard: sales stats and chart, orders table with status updates and CSV export
- Product and inventory manager plus shipping & tax rules editor
- Premium, fully responsive design for mobile and desktop
- Skills: e-commerce, Shopify-style store design, HTML5, CSS3, JavaScript, responsive UI/UX.
